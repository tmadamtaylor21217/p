`p new "需求描述"` 支持自然语言直达开发：位置参数带引号传需求（含中文或多个词）时，调用本地 claude CLI（`claude -p`，无需 API Key）生成候选项目名（可选择 / 手动输入 / 换一批），跳过模板选择直接使用空项目模板（显式 `-t` 仍可指定），创建项目后带需求描述作为初始 prompt 前台启动 claude 会话；需求同时存入项目备注。未安装 claude CLI 或生成失败/超时（60s）时回退为手动输入。移除 AI API 命名功能（`-d/--desc`、`--debug` 选项，`apiKey` / `deepseekApiKey` / `ai` 配置块），并在启动时自动清理用户配置文件中这些废弃字段（保留其余内容与注释）。
